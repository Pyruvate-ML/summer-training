# 功能扩展规划

## 第一阶段：前端页面和业务模型

- 完成概览大厅、预约排期、咨询师团队、来访者档案。
- 明确预约、咨询师、来访者、跟进记录的数据字段。
- 提供静态数据和基础交互。

## 第二阶段：后端接口

- 用户登录和角色权限。
- 预约增删改查和状态流转。
- 咨询师列表和负载统计。
- 来访者档案和跟进计划。
- 情绪趋势统计接口。

## 第三阶段：纵向业务扩展

- 咨询记录管理。
- 心理测评记录。
- 重点关注提醒。
- 咨询师排班管理。
- 数据统计报表。

## 第四阶段：工程化升级

- 前端迁移到 Vue 3 + Vite。
- 后端使用 Spring Boot 或其他团队约定框架。
- 数据库接入 MySQL。
- 增加接口文档和联调文档。
- 增加基础测试和部署说明。
