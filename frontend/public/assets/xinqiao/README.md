# 心桥心理像素风 UI 素材包

本压缩包包含从已生成素材表中拆分出的独立素材：

- `ui/`：面板、按钮、徽章、搜索框、分页等
- `icons/`：功能图标与小装饰
- `avatars/`：咨询师头像、来访者头像、姓氏块、圆形头像
- `status/`：状态徽章、风险等级、技能标签、进度条、表格条
- `env/`：房屋、树木、花草、围栏、水面、山景和边框装饰

每个目录同时提供：

- `png/`：透明背景位图，适合直接用于 Web UI
- `svg/`：由像素素材自动描摹生成的矢量路径版本

## 使用建议

像素风 UI 在网页中通常优先使用 PNG，并设置：

```css
img { image-rendering: pixelated; }
```

SVG 为自动矢量描摹结果，适合需要无损缩放或进一步在 Illustrator/Figma 中编辑的场景。由于原始素材是位图生成图，SVG 并非手工重绘，个别复杂头像和花草会包含较多路径。

详见 `manifest.json`。
